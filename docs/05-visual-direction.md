# Visual direction

## Desired character

- Minimal
- Editorial
- Technical
- Quietly confident
- Precise
- Human
- Professional but relaxed
- Crafted rather than decorated

## Composition

- Compact, centered content column
- Generous but controlled section spacing
- Clear reading order
- Short line lengths
- Small number of elements on screen at once
- No excessive scrolling for the amount of content shown
- Full-width media only when it materially improves a project story
- A centered, compact identity block replaces a traditional navigation bar

## Typography

Use Inter Variable throughout.

- One family keeps the interface quiet.
- Confidence comes from hierarchy, spacing, and writing rather than extreme weight.
- Avoid extra-bold headlines.
- Use restrained tracking and a compact scale.
- Use tabular figures for metrics.
- Do not add a serif or decorative display family.

## Color

Use a predominantly neutral palette.

Dark mode:

- Near-black background
- Warm off-white primary text
- Neutral-grey secondary text
- Low-contrast borders and surfaces

Light mode:

- Slightly warm off-white background
- Deep charcoal primary text
- Medium-grey secondary text
- Subtle cool-grey boundaries

No permanent blue is required. The FB mark should inherit the current text color.

## Logo

Use the existing FB mark without changing its geometry.

Primary lockup:

`[FB mark] Frederic Berghmans`

Implementation should replace the SVG's fixed fill with `currentColor`.

On the homepage, the portrait, name, title, social links, and positioning copy form one centered introduction. The name is the semantic page heading but should remain visually subtle rather than display-sized.

## Portrait

The portrait should be editorial rather than corporate:

- Monochrome
- Transparent background
- Head and upper shoulders
- Body angled 20 to 30 degrees
- Face looking slightly away or upward
- Relaxed and thoughtful expression
- Plain dark clothing
- Directional soft light
- Natural skin texture
- Subtle grain
- No artificial glossy skin or obvious generative artifacts

High-resolution personal photos will be used as identity references for a newly generated portrait.

## Personality

Personality comes from:

- Copy
- Typography
- Spacing
- Portrait composition
- Precise motion
- Subtle optional sound
- Theme behavior
- Technical interaction details

## Prohibited visual patterns

- Glow effects
- 3D decoration
- Gradients used as atmosphere
- Glassmorphism
- Floating blobs or orbs
- Generic feature-card grids
- Excessive rounded cards
- Oversized type that forces unnecessary scrolling
- Decorative code snippets
- Fake terminal interfaces
- Generic AI-generated illustrations
- Multiple font families
- Continuous cursor effects
